Findings

SevCategoryDescriptionFix
HighSecurity / trust One SIWS signature is stretched into the 12-word coldkey and the transit secp256k1 key. Anyone who obtains that signature owns the Bittensor wallet. Domain-binding is the control. CSP script-src 'self' is load-bearing. Keep signInFields domain/URI frozen (already tested ASCII). Never log signatures. Do not add third-party scripts. Surface the hardware-wallet “non-standard signature” warning; it is already there.
HighCorrectness Unstake, Move, the batched 0.25% Bittensor fee, a subnet stake through the live page, and first-time Solana token-account arrival are enabled without real-funds proof. Only free-TAO return and a root forward stake are proven. One approved live-origin run each: root stake, subnet stake with addStakeLimit, partial unstake, return to a fresh ATA. Until then, do not tell partners “the full loop works”.
HighCorrectness Completion is inferred from a Solana TAO balance delta, not from the OFT receive. Parse the LayerZero / OFT receive, or label the tracker as observed balance rather than verified delivery.
MediumError handling / ops Solana RPC is a single PublicNode URL after Helius 403. Bittensor lite RPC 429s fail directory and page tests. confirmSignature can poll forever if height never advances. Add a fallback origin already allowed in CSP (Helius once the plan is restored, or a second public endpoint). Cap confirm wait. Treat processed as in-flight, not success.
MediumSecurity Chutes top-up cannot prove the pasted SS58 is a Chutes payment address. Gated (chutesLive: false). Enabling it without a credited test loses funds to a wrong paste. Leave gated until one ≥0.01 TAO top-up is credited by Chutes. Keep the acknowledgement copy.
LowOrganization app.js owns connect, derive, quotes, send, resume, holdings, return, directory, and Chutes. Split by controller. Do not grow Chutes inside it first.

What is solid (do not “fix” these into something worse)

  • No innerHTML for fund UI; phrase rendered as text nodes.
  • Simulate the Solana tx before the wallet prompt; skipPreflight: false.
  • Pending routes HMAC-sealed from the in-memory transit key; untrusted records pay only the wallet on screen.
  • Subnet stakes use addStakeLimit at 2%; hotkeys checked on the chosen netuid.
  • Keys live in memory and are dropped on pagehide.
  • No WalletConnect (standing constraint). SIWS statement is plain ASCII.
